Look up a member by their 6-digit member number in CoreVue and return the current balance of their S1 savings share account.

TAKES
  memberId           string  matching ^\d{6}$  [pii]
                     The member's 6-digit CoreVue member number.
  expectedName       string  [pii]
                     Optional. Part of the member's name as the caller knows it, e.g. "Rosa". When supplied, the capability asserts the record on screen belongs to that person before reading anything off it, and returns MEMBER_NAME_MISMATCH if it does not. Omit it to skip the check.
  operatorId         string  [secret]
                     Operator ID for the CoreVue sign-on. Supplied by the runtime environment, never by the caller.
  operatorPassword   string  [secret]
                     Password for the CoreVue operator sign-on. Supplied by the runtime environment, never by the caller.

RETURNS
  savingsBalance     money  [pii]  — Current balance of the S1 savings share account, without the currency symbol.
  memberName         string  [pii]  — Name on the member record that was actually read, as displayed by CoreVue.

  MEMBER_NAME_MISMATCH     The member number resolved to a different person than the caller named. Reading this record would be acting on the wrong account, so the run stops without returning a balance.
